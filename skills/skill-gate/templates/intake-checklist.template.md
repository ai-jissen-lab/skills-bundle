# 外部スキル取り込み前チェック（テンプレート）

外部スキル・プラグインを取り込む前に、上から順に確認する。途中で落ちたら、そこで終了。

- [ ] 配布元の素性を確認した（公式か、個人か、再配布か）
- [ ] 中身の構成を確認した（指示文のみか、実行コードを含むか）
- [ ] SkillSpector（v2.12.0）で `--no-llm` スキャンを実行した
- [ ] 判定を確認した（DO NOT INSTALL なら即終了した）
- [ ] HIGH の場合、指摘箇所を原文で実地確認し、誤検知の理由を記録した
- [ ] 移植範囲をプロンプト部分のみに限定した（実行コードは原則入れない）
- [ ] 外部送信にあたる処理が含まれていないか確認した
- [ ] 自分の常駐ルールと矛盾する指示がないか確認した
- [ ] 取り込み後に動作確認をした（狙った場面で動くか、既存と競合しないか）
- [ ] スキルの素性を1行で言える形で記録した
