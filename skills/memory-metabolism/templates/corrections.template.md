# 訂正台帳（テンプレート）

過去に持ち主が訂正した事実の一覧。ここの項目は、棚卸しの削除・移設候補から必ず外す。整理の前後の検証では、ここから最低3問を選んで再質問する。

| # | 論点 | 旧（誤） | 現行（正） | 訂正された日 | 検証質問の形 |
|---|---|---|---|---|---|
| 1 | （例：公式サイトのキャンセル規定） | （例：規定があると書いた） | （例：公式サイトに明記はない） |  | （例：「キャンセル規定はどこに書いてある？」） |
| 2 |  |  |  |  |  |

- 「旧（誤）」の列は、間違いを再発させないために残す。現行の答えと混同しないよう、必ず「旧（誤）」と分かる形で書く。
- 新しい訂正が起きたら、その日のうちにここへ1行足す。台帳への追加は承認不要（消す・移すときだけ承認制）。
