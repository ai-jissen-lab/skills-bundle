# 設定

memory-metabolismは、このフォルダに`config.md`があればその値で動き、最初の質問を飛ばす。使うときはこのファイルを`config.md`という名前でコピーし、値を書き換える。書いていない項目は既定値になる。

| 項目 | 値 |
|---|---|
| 常駐ファイル | MEMORY.md, AGENTS.md |
| シーン別フォルダ | memory/scenes/ |
| 日次ログフォルダ | memory/ |
| アーカイブフォルダ | memory-backup-YYYY-MM-DD/（整理のたびに日付で作る） |
| 常駐の上限の目安 | 合計30,000字（50,000字超は危険圏） |
| チェックの頻度 | タスク開始時に軽く、棚卸しは週1回 |
| 承認者 | メモリの持ち主本人 |

常駐ファイル名は環境に合わせて書き換える（Claude CodeならCLAUDE.md、他のエージェントならそのメモリファイル）。承認者は、整理の適用を判断する人の名前や呼び方を書く。
