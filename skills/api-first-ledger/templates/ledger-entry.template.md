# API台帳 1件分の記録（テンプレート）

台帳（API台帳ファイル）に、APIごとにこの形で記録する。後から「なぜ入れたのか」「条件は何だったか」を読み戻せることが目的。

---

## ［API名］
- 能力：［何ができるか。仕事の言葉で書く。「○○の検索」「○○の取得」など］
- 接続状態：［接続済み／キー待ち／キー不要］
- 無料枠：［上限と条件。超過時は止まる／課金される、まで書く］
- 商用利用：［可／不可（規約で確認した日付）］
- 優先順位：［同じ能力が複数あるときの順位。無料 ＞ 高速 ＞ 高精度で決める］
- 確認日：［条件を確認した日］
- 備考：［失敗しやすい条件、失敗した理由の記録、フォールバック先］

---

書き方のポイント：

- 能力は「仕事の言葉」で書く。台帳はAI側が引くものだが、仕事の言葉で引ける形にしておくと、作業の依頼文からそのまま対応づけられる
- 無料枠は上限だけでは不十分。超えたときに止まるのか、自動で課金されるのかで、運用のリスクがまったく違う
- 確認日は必ず付ける。無料の条件は変わるものだ。記録した時点の条件であることを日付で示し、条件が変わったことに気づいたらその場で台帳を直す
