# 無料APIの採用前チェック（テンプレート）

新しいAPIを台帳に取り込む前に、上から順に確認する。除外条件に1つでも当てはまれば、取り込まない。

- [ ] 料金ページで無料枠の有無と上限を確認した
- [ ] 超過時の扱いを確認した（自動課金されるものは取り込まない）
- [ ] 従量課金のみではない（無料枠が継続して存在する）
- [ ] 初回クレジット頼みではない（クレジットが尽きても無料で使える）
- [ ] カード必須のトライアルではない
- [ ] 終了・改定の告知が出ていない
- [ ] 利用規約で、法人の商用利用が無料枠に含まれることを確認した
- [ ] 継続性に不安がない（提供元の体制を見た）
- [ ] 台帳に、能力・接続状態・無料枠の条件・確認日を記録した
- [ ] 実際に接続し、想定どおり無料で動くことを確認した
