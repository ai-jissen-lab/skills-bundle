# 仕上げのNG点検 チェックリスト

スライドを出す前に、1枚ずつ当てはまるものがないか見る。当てはまったら直してから出す。
点検項目の一部はKAWAI（@kawai_design）の図解を参考に、スライド制作の点検用に再構成。

## 文字加工・組み方

- [ ] フチ文字：文字にフチ・袋文字を使わない。背景との明暗差で読ませる
- [ ] ドロップシャドウ：文字・カードに影を付けない。余白と色面で情報を分ける
- [ ] 光彩・グロー：文字や図形を発光させない。色と大きさで強調する
- [ ] 立体文字・ベベル：文字を立体化・押し出ししない。フラットな字形を保つ
- [ ] 長体・平体：文字を縦横に伸縮しない。文字サイズと改行で収める
- [ ] 斜体・文字の傾き：文字を傾けたり回転させない。水平に配置する
- [ ] 単語の途中で改行：単語の途中で改行しない。意味のまとまりで行を分ける
- [ ] 読めない小さい文字：詰めるために文字を縮めない。文を短くし、読めるサイズにする

## 線・カード・飾り

- [ ] 区切り線の多用：区切り線は可能な限り減らす。必要な関係線だけ残す
- [ ] 囲み線の多用：枠線で全要素を囲まない。余白と背景の色面で分ける
- [ ] 装飾的な下線：見出しに装飾の下線を引かない。太さと文字サイズで差を付ける
- [ ] カード上部の色帯：カード上部に飾りの帯を足さない。見出しと余白で整理する
- [ ] カード左側の色帯：カード左端に飾りの帯を足さない。配置と色面でまとまりを作る
- [ ] ちょんちょん・放射線：文字の周りに強調線を足さない。大きさと余白で目立たせる
- [ ] 意味のないアイコン：内容と関係のない飾りを置かない。意味を伝える図だけ残す
- [ ] 角丸カードの乱用：すべてを角丸カードにしない。情報の関係に合う配置を選ぶ

## 色・余白・構成

- [ ] 目的のないグラデ：装飾目的でグラデを使わない。色の役割を決め、単色で整える
- [ ] ノイズ・紙の質感：意図しない粒・かすれを足さない。背景の色面は滑らかに保つ
- [ ] 強調色の使いすぎ：重要語を何色にも塗り分けない。強調色を絞り、役割をそろえる
- [ ] すべてを太く大きく：全要素を同じ強さにしない。主役を1つ決め、補足は弱める
- [ ] なんでも中央揃え：長い説明まで中央にそろえない。本文は左端をそろえる
- [ ] 余白を飾りで埋める：空いた場所を装飾で埋めない。関連する情報をまとめ、余白を残す
- [ ] 背景と同化する文字：薄い文字や低コントラストを避ける。背景との明暗差を確保する
- [ ] 同じ構図の使い回し：内容を無視して型を使い回さない。関係に合う図にする
