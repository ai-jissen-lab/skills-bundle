# 成果物の受け取りチェック（テンプレート）

委任した仕事の納品・報告を受けたら、その場で確認する。「完了」と言われたものほど当てる。

- [ ] 成果物が、仕様に書いた形式・保存先どおりにある
- [ ] 「含めない要素」が混ざっていない
- [ ] 完了の証拠が示されている（番号・URL・履歴・読み戻しなど）
- [ ] 証拠を自分の側でも1つ確認した（公開URLを開く、等）
- [ ] 「残り」が明示されている（未実施の部分が完了の顔をしていないか）
- [ ] 集計や台帳に影響する数字は、正本を読み戻してから動かした
- [ ] 別の場所に未確定の下書き・予約が残っていない（二重実行の防止）

最後の項目は見落としやすい。失敗したと思った前回の試みが下書きや予約の形で残っていて、後から二重に実行される事故がある。
