# メール下書き前の確認（テンプレート）

下書きを書き始める前に、上から順に確認する。1つでも埋まらない項目があれば、書く前にそちらを先に片づける。

- [ ] スレッド全体を原文で読んだ（要約・件名だけで判断していない）
- [ ] 相手の最新メールだけでなく、自分の送信済みも読み返した
- [ ] 添付ファイルをすべて開いて、中身を確認した
- [ ] 相手が求めていることと、まだ決まっていないことを分けて書き出した
- [ ] 見積・請求・人数・日程・支払条件など、数字と条件の整合を確認した
- [ ] すでに他で対応済みでないか確認した（別の担当・別の手段で返事していないか）
- [ ] 宛先が合っているか確認した（返信先、Ccの要否）

効くのは、真ん中の項目。「求めていることと未決事項を分ける」は書く前に書き出す作業で、「数字と条件の整合」は書く段ではなく確認の段でしか防げない取り違えを止める。「他で対応済みでないか」は、二重の返信を防ぐ。
