# 訂正台帳（テンプレート）

訂正された事項だけを集めた一覧。1件につき1行。ここの項目は、メモリ整理の削除・移設候補から必ず外す。整理の前後の検証では、ここから論点の違う3問ほどを選んで再質問する。

| 論点 | 旧（誤） | 現行（正） | 訂正日 | 検証質問の形 |
|---|---|---|---|---|
| 資料の置き場所 | 共有フォルダの直下 | プロジェクトごとのフォルダの中 | （例：2026-11） | 「〇〇の資料はどこに置く？」 |
| 会議の日時の扱い | 候補日を確定として案内した | 確定の返事が来るまでは候補と明示する |  | 「〇〇の日程は確定している？」 |
| 呼び方の表記 | 略称で統一 | 正式名称で書く。略称は社内だけ |  | 「対外文書で〇〇はどう表記する？」 |

（例は一般化した形。実際は自分の環境で直した事実が並ぶ）

運用ルール：

- 追加は承認不要で、その日のうちに。消す・移すときだけ承認制
- 「旧（誤）」も残す。正しい答えだけでは、AIが古い記述を拾ったときにどちらが現行か判定できない
- 「検証質問の形」は、整理の前後で答えが崩れていないかを確かめる再確認に使う
